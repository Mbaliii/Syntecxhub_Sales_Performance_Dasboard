# Sales Performance Dashboard

An end to end Data Analytics project that imports, cleans, and anlyzes sales transaction data using #Python(Pandas) and builds and interactive visualization dashboard in #Power BI(Tableau).
## Project Overview ##
This project provides business insights into sales growth, product performance and regional sales distribution.
The main objective is to convert raw, messy transactional data into actionable financial KPIs(Key Performance Indicator) and clean visual dashboards to support data-driven business decisions.
1. Data Cleaning and Processing : Remove duplicate oreder records, handling missing values, standardize data and numeric data types using #Python.
2. Trend & Time-Series Analysis : Track Monthly, quaterly and yearly performance velocity.
3. Product & Category Insights : Identify top-performing driver items contra low-margin or underperforming products.
4. Regional Comparison : Analyze geographical and category-level revenue and profit distributions.
5. KPI(Key Performance Indicator) Metrics Creation : Compute Total Revenue, total Profit, Profit Margin % and sales volume

## Tech Stack & Tools
Programming Language : Python 3.x
Data Manipulation : Pandas, NumPy
Visualization : Power BI /Tableau
Version Control : Github
